# 전산근무표 관리 프로그램 (WBMS) 기획서

## 1. 개요

전산근무에 투입되는 인원을 등록하고, 각 인원의 휴가·식기 배식 등 **불가 일정**을 입력하면
일정이 겹치지 않도록 **전산근무표를 자동 생성**하는 프로그램이다.

- 수기로 근무표를 짤 때 생기는 일정 충돌을 없앤다.
- 인원별 근무 횟수를 고르게 배분한다.
- 생성된 근무표를 확인·수정·출력할 수 있게 한다.

## 2. 용어

| 용어 | 설명 |
| --- | --- |
| 근무자 | 전산근무에 투입되는 인원 (계급 + 이름). 예: `일병 김철수` |
| 불가 일정 | 근무자가 근무를 설 수 없는 기간. 휴가, 식기 배식 등 |
| 근무 슬롯 | 근무 한 칸. 날짜 + 시간대(오전/오후) |
| 근무표 | 기간 내 모든 근무 슬롯에 근무자를 배정한 결과 |

## 3. 근무 규칙

| 요일 | 근무 | 비고 |
| --- | --- | --- |
| 월 ~ 목 | 오전 1명, 오후 1명 | 오전·오후 각각 배정 |
| 금 | 오전·오후 **같은 1명** | 하루 통째로 한 사람이 선다 |
| 토·일 | 근무 없음 | |

## 4. 주요 기능

### 4.1 근무자 관리
- 근무자 추가 / 수정 / 삭제
- 입력 항목: 계급(이병·일병·상병·병장), 이름
- 활성/비활성 상태 (전역·전출 등으로 빠지는 인원은 비활성 처리)

### 4.2 불가 일정 관리
- 근무자별로 불가 일정 등록
  - 예: `일병 김철수` — 휴가, `10.08 ~ 10.10`
  - 예: `상병 홍길동` — 식기 배식, `10.13`
- 입력 항목: 근무자, 사유(휴가 / 식기 배식 / 기타), 시작일, 종료일, 시간대(종일 / 오전 / 오후)
  - 식기 배식처럼 하루 중 일부만 빠지는 경우를 위해 시간대를 지정할 수 있게 한다.

### 4.3 근무표 생성
- 생성 기간(시작일 ~ 종료일)을 지정하면 해당 기간의 근무 슬롯을 만들고 근무자를 배정한다.
- **필수 조건 (Hard)**
  1. 불가 일정과 겹치는 슬롯에는 배정하지 않는다.
  2. 금요일은 오전·오후 모두 가능한 1명만 배정한다.
- **권장 조건 (Soft)**
  1. 근무 횟수를 인원 간 최대한 균등하게 배분한다. (금요일은 오전+오후 2회로 계산)
  2. 같은 날 오전·오후를 한 사람이 연달아 서는 것을 피한다. (월~목)
  3. 같은 사람이 연속된 날에 몰리지 않도록 한다.
- 배정 가능한 인원이 없는 슬롯은 **빈칸으로 두고 경고**를 표시한다.

### 4.4 근무표 확인 및 수정
- 주/월 단위 표 형태로 표시
- 특정 슬롯의 근무자를 직접 변경 가능 (변경 시 불가 일정 충돌 여부 검사)
- 인원별 근무 횟수 통계 표시

### 4.5 내보내기
- 근무표를 인쇄용 화면 / 엑셀(CSV) 형태로 내보내기

## 5. 배정 알고리즘 (초안)

1. 기간 내 평일 날짜를 순서대로 순회한다.
2. 각 슬롯마다 **배정 가능한 후보**를 추린다.
   - 불가 일정이 없는 근무자
   - 금요일이면 오전·오후 모두 가능한 근무자
3. 후보 중 **누적 근무 횟수가 가장 적은 사람**을 고른다.
   - 동률이면 마지막 근무일이 가장 오래된 사람 → 그래도 동률이면 무작위
4. 후보가 없으면 빈칸 + 경고.

> 단순 탐욕(greedy) 방식으로 시작하고, 필요하면 이후 제약 만족(백트래킹) 방식으로 개선한다.

## 6. 데이터 모델 (초안)

```text
Person
  id, rank, name, active

Unavailability
  id, personId, reason(휴가|식기배식|기타), startDate, endDate, period(종일|오전|오후)

Schedule
  id, startDate, endDate, createdAt

Assignment
  scheduleId, date, period(오전|오후), personId (nullable)
```

## 7. 화면 구성 (초안)

1. **근무자 목록** — 근무자 추가/수정/삭제
2. **불가 일정** — 근무자별 휴가·식기 배식 등록, 달력 형태로 확인
3. **근무표 생성** — 기간 선택 → 생성 → 결과 미리보기
4. **근무표 보기** — 표 형태 확인, 수동 수정, 통계, 내보내기

## 8. 예시

근무자: `일병 김철수`, `상병 홍길동`, `병장 이영희`
불가 일정: `일병 김철수` 휴가 10.08(목) ~ 10.10(토)

| 날짜 | 오전 | 오후 |
| --- | --- | --- |
| 10.05(월) | 일병 김철수 | 상병 홍길동 |
| 10.06(화) | 병장 이영희 | 일병 김철수 |
| 10.07(수) | 상병 홍길동 | 병장 이영희 |
| 10.08(목) | 상병 홍길동 | 병장 이영희 |
| 10.09(금) | 상병 홍길동 | 상병 홍길동 |

→ 김철수는 휴가 기간(10.08 ~ 10.10)에 배정되지 않고, 금요일은 한 사람이 오전·오후를 모두 선다.

## 9. 범위 및 추후 고려사항

- **1차 범위 (MVP)**: 근무자 관리, 불가 일정 관리, 근무표 자동 생성, 표 보기
- **추후 고려**
  - 공휴일 자동 제외
  - 계급별 배정 규칙 (예: 신병 단독 근무 제한)
  - 근무 교대 요청 / 변경 이력
  - 지난 근무표 누적 횟수를 다음 생성에 반영
- **미정 사항**: 기술 스택(웹 / 데스크톱), 데이터 저장 방식(로컬 파일 / DB)
