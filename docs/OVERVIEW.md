# 전산근무표 관리 프로그램 (WBMS) 기획서

## 1. 개요

전산근무에 투입되는 인원을 등록하고, 각 인원의 휴가·식기 배식·비번 등 **불가 일정**을 입력하면
일정이 겹치지 않도록 **월 단위 전산근무표를 자동 생성**하는 프로그램이다.

- 수기로 근무표를 짤 때 생기는 일정 충돌을 없앤다.
- 월 안에서 인원별 근무 횟수를 고르게 배분한다.
- 생성 후 변경은 **근무자 간 변경 요청 → 상대방 승인** 방식으로 처리한다.
- 결과를 엑셀로 내보낸다.

## 2. 개발 제약 (가장 중요)

| 항목 | 내용 |
| --- | --- |
| 사용 환경 | 부대 인트라넷 PC (외부 인터넷 불가) |
| 반입 방식 | 작성된 코드를 **인쇄 후 직접 받아 적어서** 옮긴다 |
| 코드량 | **최소화**. 목표: 파일 1개, 300줄 내외 |
| 외부 라이브러리 | 사용하지 않음 (받아 적을 수 없음) |
| 서버 | 만들지 않음 (코드량 증가) |
| 데이터 저장 | 외부 서버 없이 **로컬 파일 또는 브라우저 로컬 스토리지** |

→ **`index.html` 한 파일**(HTML + CSS + 순수 JavaScript)로 만들고, 브라우저(Edge/Chrome)로 열어서 쓴다.

## 3. 사용자와 권한

| 사용자 | 할 수 있는 일 |
| --- | --- |
| 작성자 (나) | 근무자·불가 일정·휴무일 관리, 근무표 생성, 직접 수정 |
| 근무자 전원 | 근무표 보기, 변경 요청 보내기, 자기에게 온 요청 승인/거절 |

- 로그인은 만들지 않는다. 화면 상단에서 **"나는 누구"**를 이름으로 선택한다. (코드량 절감, 신뢰 기반)

## 4. 근무 규칙

| 요일 | 근무 | 시간 | 인원 |
| --- | --- | --- | --- |
| 월 ~ 목 | 오전 | 08:00 ~ 13:30 | 1명 |
| 월 ~ 목 | 오후 | 13:30 ~ 17:30 | 1명 (오전과 **다른 사람**) |
| 금 | 종일 | 08:00 ~ 16:00 | 1명 |
| 토·일, 공휴일, 대체휴일, 부대 휴무일 | 근무 없음 | | |

- 공휴일·대체휴일·부대 휴무일은 인터넷으로 가져올 수 없으므로 **작성자가 휴무일로 직접 등록**한다.
- 연속 근무(전날·다음날, 금→월)는 제한하지 않는다.

## 5. 주요 기능

### 5.1 근무자 관리 (작성자)
- 추가 / 삭제
- 입력 항목: 계급(이병·일병·상병·병장), 이름

### 5.2 불가 일정 관리 (작성자)
- 입력 항목: 근무자, 사유, 시작일, 종료일, 시간대(종일 / 오전 / 오후)
- 사유: **휴가 / 식기 배식 / 비번 / 기타**
  - 비번: 당직 근무 후 받는 휴무. 불가 일정으로 등록한다.
- 기간은 **시작일·종료일 모두 종일 불가**로 본다.
  - 예: `일병 김철수` 휴가 `10.08 ~ 10.10` → 10.08 오전, 10.10 오후 모두 불가

### 5.3 휴무일 관리 (작성자)
- 공휴일·대체휴일·부대 휴무일을 날짜로 등록한다. 해당 날짜에는 근무 슬롯을 만들지 않는다.

### 5.4 근무표 생성 (작성자)
- **월**을 선택하면 그 달의 근무 슬롯을 만들고 근무자를 배정한다.
- **필수 조건**
  1. 불가 일정과 겹치는 슬롯에는 배정하지 않는다.
  2. 월~목: 같은 날 오전·오후는 서로 다른 사람.
  3. 금: 종일(오전·오후 모두) 가능한 1명.
- **균등 배분**: 그 달 안에서만 근무 횟수를 균등하게 맞춘다. (지난달 누적은 반영하지 않음)
- 배정 가능한 사람이 없는 슬롯은 **빈칸 + 경고 표시**.

### 5.5 근무표 보기 (전원)
- 월 단위 표로 표시: 날짜 / 오전 / 오후 (금요일은 한 칸 병합)
- 인원별 이번 달 근무 횟수 표시

### 5.6 변경 요청 (전원)
1. 요청자가 **자기 근무 슬롯**을 고르고, **받을 사람**을 고른다.
   - **교대**: 상대방의 슬롯과 서로 맞바꿈
   - **대신 서기**: 상대방이 내 슬롯을 대신 섬
2. 받는 사람이 화면에서 **승인 / 거절**한다.
3. 승인 시 불가 일정·같은 날 오전/오후 규칙을 다시 검사하고, 문제가 없으면 근무표에 반영한다.
4. 요청 상태: `대기 / 승인 / 거절`

### 5.7 엑셀 내보내기
- 라이브러리 없이 **CSV 파일**(UTF-8 BOM 포함)로 저장한다. 엑셀에서 바로 열린다.
  - 진짜 `.xlsx`는 라이브러리가 필요해서 코드량이 크게 늘어난다.

## 6. 배정 알고리즘

```text
그 달의 근무일(평일 - 휴무일)을 날짜순으로 돈다.
  슬롯마다:
    후보 = 불가 일정이 없는 사람
           (금요일이면 종일 가능한 사람, 월~목 오후면 오전 근무자 제외)
    후보 중 이번 달 근무 횟수가 가장 적은 사람 선택
      동률이면 무작위
    후보가 없으면 빈칸
```

단순 탐욕(greedy) 방식으로 코드량을 최소화한다.

## 7. 데이터 저장

모든 데이터를 **JSON 객체 하나**로 관리한다.

```text
{
  people:   [{ id, rank, name }],
  offs:     [{ personId, reason, start, end, period }],  // 불가 일정
  holidays: ["2026-10-09", ...],                          // 휴무일
  schedules: { "2026-10": { "2026-10-05": { am: id, pm: id }, ... } },
  requests: [{ id, from, to, type, fromSlot, toSlot, status }]
}
```

## 8. 화면 구성

한 페이지에 탭 4개로 구성한다.

1. **근무표**: 월 선택, 표 보기, (작성자) 생성, CSV 내보내기
2. **변경 요청**: 요청 보내기, 내게 온 요청 승인/거절
3. **근무자·불가 일정**: (작성자) 등록/삭제
4. **휴무일**: (작성자) 등록/삭제

## 9. 확인이 더 필요한 사항

1. **데이터 공유 방식 (중요)**
   - 브라우저 로컬 스토리지는 **그 PC, 그 브라우저에서만** 보인다.
     "전원이 보고, 서로 요청·승인"하려면 같은 데이터를 함께 써야 한다.
   - 선택지:
     - A. **PC 한 대에서 모두 사용**: 로컬 스토리지 사용. 코드가 가장 적다.
     - B. **공유 폴더에 `index.html` + `data.json`을 둠**: 각자 열어서 쓰고 [불러오기]/[저장] 버튼으로 공유 파일을 읽고 쓴다. 코드가 조금 늘어나고, 동시에 저장하면 덮어쓸 위험이 있다.
   - 인트라넷 PC에서 공유 폴더 사용과 Edge/Chrome 버전(파일 저장 기능 지원 여부)을 확인해야 한다.
2. **금요일 근무 횟수**: 금요일 1회를 근무 1회로 볼지 2회로 볼지
3. **식기 배식**: 날짜별로 입력하는지, 정기적으로 반복되는지 (반복이면 반복 입력 기능 필요)
4. **계급별 제약**: 이병 단독 근무 가능 여부 등
5. **인원 규모**: 대략 몇 명인지
6. **작성자 직접 수정**: 작성자는 요청·승인 없이 바로 수정해도 되는지
